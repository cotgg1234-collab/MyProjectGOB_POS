# ระบบขายหน้าร้าน (POS Web Application)

เว็บแอปพลิเคชันขายหน้าร้าน พร้อมอัปโหลดรูปสินค้า แดชบอร์ดวิเคราะห์ยอดขาย และรายงานส่งออก Excel
ใช้งานภาษาไทย

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| Frontend / Backend | Next.js 16 (App Router) + TypeScript |
| UI | Tailwind CSS v4 |
| กราฟ | Recharts |
| ฐานข้อมูล | SQLite ผ่าน Prisma ORM |
| ส่งออกไฟล์ | ExcelJS |

## การติดตั้งและใช้งาน

```bash
npm install
npm run db:push
npm run dev
```

เปิด http://localhost:3000 แล้วเข้าสู่ระบบด้วย

- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `admin123`

คำสั่งอื่น ๆ

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run build` / `npm start` | build และรันแบบ production |
| `npm run db:push` | ซิงก์โครงสร้างฐานข้อมูลตาม `prisma/schema.prisma` |
| `npm run db:reset` | ล้างข้อมูลทั้งหมด เหลือแค่บัญชี admin (ใช้ตอนอยากเริ่มใหม่) |

## ฟังก์ชันหลัก

### 1. หน้าขาย (`/pos`)
- เลือกสินค้าจากการ์ดรูปภาพ กรองตามหมวดหมู่ หรือค้นหาด้วยชื่อ/รหัส
- ช่องค้นหารองรับเครื่องสแกนบาร์โค้ด — สแกนแล้วกด Enter สินค้าจะเข้าตะกร้าทันที
- ปรับจำนวน ใส่ส่วนลด เลือกช่องทางชำระ (เงินสด / โอน / บัตร) พร้อมปุ่มลัดรับเงิน และคำนวณเงินทอน
- บันทึกบิลและตัดสต็อกใน transaction เดียว แล้วแสดงใบเสร็จให้สั่งพิมพ์ได้

### 2. จัดการสินค้า (`/products`)
- เพิ่ม / แก้ไข / ลบสินค้า พร้อมหมวดหมู่ ราคาขาย ต้นทุน สต็อก และจุดแจ้งเตือนสต็อกต่ำ
- **อัปโหลดรูปสินค้า** แบบลากมาวางหรือคลิกเลือกไฟล์ (JPG/PNG/WebP/GIF ไม่เกิน 5MB) เก็บที่ `public/uploads/`
- สินค้าที่เคยขายแล้วจะถูกปิดการขายแทนการลบทิ้ง เพื่อไม่ให้ประวัติยอดขายเสียหาย

### 3. แดชบอร์ดวิเคราะห์ (`/dashboard`)
- KPI ยอดขายวันนี้ / เดือนนี้ / ปีนี้ / กำไรขั้นต้น พร้อม % เทียบเมื่อวานและเดือนก่อน
- กราฟแนวโน้มยอดขาย 30 วันล่าสุด
- สินค้าขายดี 10 อันดับ, สัดส่วนยอดขายตามหมวดหมู่, ยอดขายตามช่วงเวลาของวัน
- เปรียบเทียบยอดขายรายเดือนกับปีก่อน
- รายการสินค้าใกล้หมด และบิลล่าสุด

### 4. รายงาน + ส่งออก (`/reports`)
- เลือกช่วงรายงานได้ 4 แบบ: **รายวัน** (เลือกเดือน), **รายเดือน** (เลือกปี), **รายปี** (ย้อนหลัง 5 ปี), **กำหนดเอง** (from–to)
- แสดงสรุปยอดขาย จำนวนบิล จำนวนชิ้น กำไรขั้นต้น พร้อมกราฟและตารางแยกตามช่วงเวลา / สินค้า / บิล
- ปุ่มส่งออก **Excel** (4 ชีต: สรุป, แยกตามช่วงเวลา, แยกตามสินค้า, รายละเอียดบิล)

## โครงสร้างโปรเจกต์

```
prisma/
  schema.prisma        โครงสร้างฐานข้อมูล (User, Category, Product, Sale, SaleItem)
  seed-empty.ts        ล้างข้อมูลทั้งหมด เหลือแค่บัญชี admin
src/
  app/
    (app)/pos          หน้าขายหน้าร้าน
    (app)/products     จัดการสินค้า + อัปโหลดรูป
    (app)/dashboard    แดชบอร์ดวิเคราะห์
    (app)/reports      รายงานและส่งออกไฟล์
    login              หน้าเข้าสู่ระบบ
    api/               REST API ทั้งหมด
  components/          Shell, Receipt, ImageUploader, ProductImage
  lib/                 db, auth, format, report (รวมยอด), range (คำนวณช่วงเวลา)
  i18n/                ข้อความภาษาไทยทั้งหมด
  middleware.ts        กันไม่ให้เข้าหน้าอื่นก่อนล็อกอิน
```

## หมายเหตุด้านการนำไปใช้จริง

- รหัสผ่านเก็บแบบ scrypt hash และ session เป็นคุกกี้ HttpOnly ที่เซ็นด้วย HMAC — ก่อนใช้งานจริงให้เปลี่ยน `AUTH_SECRET` ใน `.env`
- ยอดขายย้อนหลังใช้ราคาและต้นทุนที่บันทึกไว้ในบิล (`SaleItem.unitPrice` / `unitCost`) จึงไม่เปลี่ยนตามการแก้ราคาสินค้าภายหลัง
- ถ้าจะย้ายไป PostgreSQL/MySQL แก้เพียง `datasource` ใน `prisma/schema.prisma` และ `DATABASE_URL`
- ไฟล์รูปเก็บบนดิสก์ของเซิร์ฟเวอร์ หากขึ้น host แบบ serverless ควรเปลี่ยนไปใช้ object storage
